# 📊 Digital Marketing Funnel Tree (CRUD) – C Project

## 📌 Project Overview

This project implements a **Digital Marketing Funnel** using a **Tree Data Structure in C**. It demonstrates **CRUD operations (Create, Read, Update, Delete)** to manage different stages of a marketing funnel.

The program is menu-driven and allows users to dynamically create and manage marketing stages such as Awareness, Interest, Consideration, and Conversion.

---

## 🎯 Objective

* To understand **tree data structures** in C
* To implement **CRUD operations** on hierarchical data
* To simulate a **real-world digital marketing funnel system**

---

## 🌳 Concept: Marketing Funnel as Tree

Each node in the tree represents a **marketing stage or strategy**.

Example structure:

```
Marketing Funnel
├── Awareness
│   ├── Social Media
│   │   └── Instagram
│   └── Ads
├── Interest
├── Consideration
└── Conversion
```
